# jambotron-aria-markdown-editor

Workspace of the `@jambotron/aria-markdown-editor` Angular library — the Markdown editor of Jambotron, built on Angular Aria.
Documentation: [projects/aria-markdown-editor/README.md](projects/aria-markdown-editor/README.md).
`projects/playground` — a page with the editor for development (library from source).

```bash
npm ci
npx ng test aria-markdown-editor --watch=false
npx ng serve playground
npx ng build aria-markdown-editor
```
